# Library Catalog — 66-book spine + other shelves

See `07_CANON_WHO_LEFT_WHAT_OUT.md` and `09_OLDEST_WITNESS_BY_BOOK.md`.
Compact modules now exist for every Protestant book, the deuterocanon, and Tewahedo-distinct books. Six books are GOLD.

Use this as the library home. Each line is the Door one-sentence until that book’s full module is written.
Dates below are **labels**, not verdicts. Full modules must open both chairs.

## How to use
- Status: `GOLD` = full twelve-room module exists. `DOOR` = sentence only.
- When filling a DOOR book, copy `02_BOOK_SCHEMA.md` and write all twelve rooms. Do not publish Path-only stubs as if they were finished.
